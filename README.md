# Project 02 — Outlier Detection Report

## Objective

To identify and report potential outliers in corporate credit-risk data using Excel and Python.

## Business Purpose

Extreme observations can influence model development, validation results and risk decisions. This project demonstrates a simple and reproducible approach to detecting potential outliers.

## Methods

- Interquartile Range (IQR)
- Z-score
- Excel formulas
- Python/Pandas

## Tools

- Microsoft Excel
- Python
- Google Colab
- Pandas
- NumPy

## Output

The project produces:

1. Outlier identification report
2. Number of outliers by variable
3. Percentage of observations identified as outliers
4. Excel-based validation summary
5. Python-based validation report

## Model Validation Relevance

Outlier analysis is an important component of data-quality assessment during credit-risk model validation. Identified observations should be investigated rather than automatically removed.
